# AGENTS.md

Rules for AI agents working on SAdns. Read [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md) too; their ground rules apply.

- **Update posts.** Every changelog version entry, release note, PR description and issue reply that announces a fix or status starts with the short header in [docs/UPDATE-POSTS.md](docs/UPDATE-POSTS.md). Security summaries stay generic.
- **Branches.** One branch per change, PR to `main`. Don't push to `main` or merge unless the owner asks.
