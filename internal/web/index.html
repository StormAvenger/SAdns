SAdns

Full-scope DNS & network diagnostics

Tests your OS DNS configuration, your router/local resolver and the major public resolvers over IPv4 and IPv6. It also checks failover, DNSSEC, encrypted DNS, interception and routing. The result is a technical report ready to hand to an AI assistant or a network engineer.

  • IPv4 / IPv6 connectivity
  • OS resolver path & failover
  • Router / local DNS health
  • Cloudflare · Google · Quad9 · OpenDNS …
  • UDP · TCP · DoT · DoH
  • DNSSEC validation
  • NXDOMAIN hijacking
  • Transparent DNS interception
  • Large-packet / fragmentation
  • Routing & traceroute
